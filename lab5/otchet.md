# Лабораторная работа №5. Выделение признаков символов

Вариант 5: Кириллица, строчные буквы - абвгдежѕзиiклмнопрстуфхцчшщъыьѣюѵѯѱѡѳѧѫ

Шрифт: Times New Roman, кегль 52.

Для каждой буквы алфавита создается отдельное черно-белое растровое изображение. Каждый символ сохраняется в отдельный PNG-файл в папке symbols.
Для каждого изображения вычисляется набор числовых признаков, описывающих форму символа.


## Результаты

Все скалярные признаки сведены в таблицу features.csv. Профили сохранены в виде столбчатых диаграмм PNG в папке profiles/ с правильной ориентацией осей и целочисленными подписями.
